## Usage

```sh
./alibabal.sh [nombre] [délai]
```

- **nombre** : nombre de hassanats à envoyer (par défaut infini)
- **délai** : délai entre chaque envoi en secondes (par défaut 0.5)

Exemples :

```sh
./alibabal.sh 10 1
```
*(Envoie 10 hassanats avec 1 seconde d'intervalle.)*
